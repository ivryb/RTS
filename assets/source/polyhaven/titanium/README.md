# Titanium stone source maps

Cliff Side by Dario Barresi and James Ray Cock (photography), processed by Jenelle van Heerden, from [Poly Haven](https://polyhaven.com/a/cliff_side), licensed CC0-1.0. Original 2K diffuse, OpenGL normal and roughness maps are preserved here. URLs and original checksums are in `source.json`.

`tools/assets/build_titanium_ore.py` bakes these surface details onto newly authored Dune77 ore geometry. No scanned geometry is used. The authored geometry is CC BY-SA 4.0; these source maps remain CC0.
