# Poly Haven terrain sources

Downloaded on 2026-07-29 from Poly Haven under the CC0 license.

- `aerial-beach-01-*`: [Aerial Beach 01](https://polyhaven.com/a/aerial_beach_01) by Rob Tuytel. Source for `sand-scan.webp`.
- `coast-sand-05-*`: [Coast Sand 05](https://polyhaven.com/a/coast_sand_05) by Dario Barresi and Rob Tuytel. Source for `ground-coast-sand-05.webp`.
- `dirt-aerial-03-*`: [Dirt Aerial 03](https://polyhaven.com/a/dirt_aerial_03) by Rob Tuytel. Source for `ground-dirt-aerial-03.webp`.
- `marble_cliff_02_diff_1k.jpg`: [Marble Cliff 02](https://polyhaven.com/a/marble_cliff_02) by Amal Kumar; source for the colored `cliff-marble-02.webp` cliff material.

Runtime WebP conversions are grayscale detail maps in `assets/textures/terrain/`; the live Three.js material tint owns their color. Unused experiments are kept locally under the ignored `art/workbench/` directory.
