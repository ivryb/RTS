# Terrain topology preview

This page displays the same seeded graph, height field, renderer, and walkability rules used by the game. It can switch between the authored 2D plan and rendered terrain.

Run `pnpm dev`, then open:

```text
http://localhost:5173/prototypes/terrain-topology/?view=2d&seed=77&players=2
```

Run `pnpm preview:capture:terrain-topology` for the interaction checks and reference captures.
